# 💗 Для моей любимой Кристины

Романтический сайт-подарок: заставка → галерея полароидов → окно с посланием к каждому фото → финальный сюрприз с письмом.
Работает на iPhone (Safari), Android (Chrome) и компьютере. **Без установки и сборки**: это обычные файлы, которые можно открыть браузером или выложить на GitHub Pages.

## Структура

```
kristina-gift/
├── index.html      — разметка (заставка, галерея, окно фото, сюрприз, плеер)
├── style.css       — оформление и анимации
├── app.js          — логика; вверху файла настройки фото, подписей и посланий
├── photos/         — сюда кладутся фотографии photo1.jpg … photo4.jpg
├── audio/          — сюда кладутся music.mp3, click.mp3, open.mp3 (необязательно)
└── README.md
```

## 1. Как запустить у себя

Установка зависимостей не нужна. Варианты:

- Просто открыть `index.html` двойным кликом. Всё будет работать, кроме подгрузки некоторых файлов в отдельных браузерах.
- Надёжнее: в папке проекта выполнить `python3 -m http.server 8000` и открыть `http://localhost:8000`.
- Или расширение «Live Server» в VS Code.

## 2. Куда добавлять фотографии

1. Положи фото в папку `photos/` с именами `photo1.jpg`, `photo2.jpg` … `photo8.jpg`.
2. Лучше уменьшить фото до ширины около 1200 px (вес до 400 КБ), иначе на телефоне будет долго грузиться.
3. Формат HEIC с iPhone браузеры не открывают: переведи в JPG (на iPhone: «Файлы» → скопировать как JPG, или отправь фото себе в мессенджере сжатым).
4. Пока фото нет, вместо них показываются нежные заглушки с подсказкой, какой файл куда класть.

Нужно больше или меньше фотографий (рекомендуется 4–10)? Добавь или удали строки в списке `PHOTOS` в начале `app.js`.

## 3. Как менять подписи и послания

Открой `app.js`, в начале найди список `PHOTOS`. У каждой фотографии три поля:

```js
{ src: 'photos/photo1.jpg', cap: 'Подпись под фото', msg: 'Послание в окне при нажатии' }
```

Текст письма в финале лежит в `index.html` внутри блока `<article class="letter">`.

## 4. Как добавить музыку

- Положи файл `audio/music.mp3` (фоновая музыка, играет по кругу). Для нажатий можно добавить очень короткие `audio/click.mp3` и `audio/open.mp3`.
- Используй только свои записи или музыку с разрешённой лицензией (например, Pixabay Music, Free Music Archive). Случайные треки из интернета в публичном сайте использовать нельзя.
- Если файлов нет, сайт не ломается: вместо них играет встроенная нежная мелодия и тихие звуки нажатий.
- Safari на iPhone запускает звук только после нажатия, поэтому музыка включается кнопкой «Открыть моё сердце». Состояние плеера (вкл/выкл и громкость) запоминается на время посещения.
- Если на iPhone включён беззвучный режим (переключатель сбоку), звука не будет.

## 5. Как опубликовать и отправить ссылку

**GitHub Pages (бесплатно):**

1. На github.com создай публичный репозиторий, например `for-kristina`.
2. «Add file → Upload files»: перетащи **содержимое** папки (`index.html`, `style.css`, `app.js`, папки `photos` и `audio`) и нажми Commit.
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты ссылка будет такой: `https://ТВОЙ-ЛОГИН.github.io/for-kristina/`. Отправь её Кристине.

Через git в терминале:

```bash
git init && git add . && git commit -m "gift"
git branch -M main
git remote add origin https://github.com/ТВОЙ-ЛОГИН/for-kristina.git
git push -u origin main
```

Совет: репозиторий публичный, поэтому его фото увидит любой, у кого есть ссылка. Если это неприятно, возьми хостинг с приватной ссылкой (например, Netlify Drop: перетащить папку на netlify.com/drop).

**Добавить на главный экран iPhone:** Safari → «Поделиться» → «На экран “Домой”».
